# EulerGPU
Pytorch-based implementation of Euler registration using GPU acceleration.

## Installation

To install, simply clone this package and then install with `pip`:

```
git clone git@github.com:flavell-lab/euler_gpu.git
cd euler_gpu
pip install .
```
